# Winning Static References — EVOLVE 2026

44 proven Meta static ads, properly labelled with concept name + awareness stage + category.

## Filename format

`{section}_p{page}_{concept-name}_{awareness}_{category}.png`

- **section**: `metastatic` (Meta Statics from EVOLVE) or `worldclass` (World Class Statics)
- **page**: original EVOLVE deck page number for cross-reference
- **concept-name**: the methodology label (Avatar Call Out, Solution Exaggeration, Image With Context, etc.)
- **awareness**: target awareness stage (unaware, problem-aware, solution-aware, product-aware, most-aware, brand-aware, offer-focused)
- **category**: HEALTH, WEALTH, or RELATIONSHIPS — what the original ad sells against

## Installation

Drop all 44 PNG files into `~/Documents/NailedIt-Cowork/winning-statics/`.
Drop INDEX.md into `~/Documents/NailedIt-Cowork/references/winning-statics-index.md`.

INDEX.md is the lookup key — Cowork reads it to pick the right reference for each nightly concept based on:
1. Awareness stage match (most important)
2. Category match (Health/Wealth/Relationships — bonus relevance)
3. Methodology fit (Avatar Call Out for identity-led concepts, Solution Exaggeration for bold problem framing, etc.)

## What this enables

The nightly task can now reason: "For my Gel Allergy Escapee + M2 + Problem Aware concept, the Avatar Call Out methodology is the best structural match. I'll use the matching PNG as visual reference."

Without this labelling, references were random. Now they're matched.
